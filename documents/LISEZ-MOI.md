# documents : les documents du projet CT-CORA3D

| Document | Contenu |
|---|---|
| `CT-CORA3D_Dossier_complet.pdf` | le projet de A à Z (sources LaTeX dans `dossier_complet/`, refaire avec `bash dossier_complet/construire.sh [figures]`) |
| `cahier_des_charges/` | cahier des charges fonctionnel (LaTeX, avec les deux plans du guide générique) |
| `cahier_des_charges_it/` | cahier des charges informatique (LaTeX) |
| `justification_guide/` | justification du guide générique : os de référence, dimensions, broches |
| `plan_guide_generique/` | plans 2D du guide de coupe et du guide de réduction (DWG, DXF, PDF), dessinés dans CADCraft par `script/plans_generiques.py` |
| `archives/` | anciens documents du 23/10/2026 (rapport Word, figures, sources Markdown), remplacés par les documents ci-dessus |

Les dossiers LaTeX s'ouvrent dans Overleaf : New Project, Upload Project, avec le fichier `<dossier>_overleaf.zip`
(ces zips ne sont pas sur GitHub ; les recréer en compressant `main.tex` et `images/`).
